[Live Demo](https://resolveai-p3rr.onrender.com/) ·
[Source Code](https://github.com/Sonu0701/resolveai)

A policy-aware customer-support copilot that investigates tickets, verifies SQLite order facts, retrieves policy evidence, applies deterministic eligibility rules, and pauses risky cases for manager approval.

**Engineering highlights:**

- Built an explicit LangGraph workflow with conditional approval routing
- Separated LLM reasoning from binding Python business rules
- Implemented separate Chroma collections for policies and historical cases
- Added durable SQLite case history, audit logs, and LangGraph checkpoints
- Used `interrupt()` and `Command` for approve, reject, and edit-and-approve flows
- Added PII masking, prompt-injection detection, citations, and safe draft-only actions
- Created a 32-case evaluation harness and pytest regression suite
- Packaged the application with Docker and deployed it on Render

**Stack:** Python · LangGraph · LangChain · Mistral · ChromaDB · SQLite · Pydantic · Streamlit · pytest · Docker
