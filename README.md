## 🚀 Featured Projects

### 🤖 [ResearchMind — Multi-Agent AI Research System](https://github.com/Sonu0701/multi-agent-ai-research-system)
> **[🌐 Live Demo](https://multi-agent-ai-research-system-zr25.onrender.com)**

A 5-agent autonomous pipeline that researches any topic, scrapes the web, and generates structured reports — with a **Critic Agent scoring each report 1–10** and requesting revisions until quality is met.

`Python` `LangChain` `Mistral AI` `Tavily API` `BeautifulSoup4` `Streamlit` `Docker` `Render`

**Key highlights:**
- 🧠 5-agent pipeline: Search → Extract → Read → Write → Critique
- ⚖️ LLM-as-a-judge evaluation loop for iterative quality improvement
- 🔍 Real-time web search via Tavily API + noise-free scraping

### 💬 [Dynamic RAG Chatbot](https://github.com/Sonu0701/dynamic-rag-chatbot)
> **[🌐 Live Demo](https://dynamic-rag-chatbot-tgpt.onrender.com)**

A production RAG system that lets you upload any PDF and chat with it — with **multi-turn memory, dynamic Pinecone indexing, and real-time source citations**.

`Python` `FastAPI` `LangChain` `Pinecone` `Mistral AI` `React.js` `Docker` `Render`

**Key highlights:**
- 📄 Context-aware PDF querying with multi-turn conversation memory
- 🗄️ Dynamic Pinecone strategy — auto-removes stale embeddings on new upload
- ⚛️ React.js frontend with dark mode + real-time source tracking
