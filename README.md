<p>
  <a href="https://resolveai-p3rr.onrender.com/">

  </a>
</p>

A policy-aware customer-support copilot that investigates tickets, verifies SQLite order facts, retrieves official policy evidence, applies deterministic eligibility rules, and pauses high-risk cases for manager approval.

### Engineering highlights

- Built an explicit **LangGraph workflow** with conditional approval routing
- Separated LLM classification and drafting from binding Python business rules
- Implemented separate Chroma collections for official policies and historical cases
- Added durable SQLite case history, audit logs, and LangGraph checkpoints
- Used `interrupt()` and `Command` for approve, reject, and edit-and-approve paths
- Added PII masking, prompt-injection detection, citations, and safe draft-only actions
- Created a 32-case local evaluation harness and pytest regression suite
- Packaged the application with Docker and deployed it on Render
